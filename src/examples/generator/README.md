# Generator Example

This example demonstrates basic Generator usage. A Generator produces deterministic pseudo-random values. Using the same seed always produces the same sequence of values.

All language implementations produce identical output.

## Running the Example

From this directory, you can run the example in any language:

```bash
# Run all languages
task dir

# Run individual languages
task go
task java
task python
task typescript
```

## Expected Output

```
<random_integer>
```

Outputs a single deterministic pseudo-random integer.
