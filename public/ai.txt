# Pseudata AI Information

## Project
Pseudata is a deterministic mock data generator for polyglot software stacks. It ensures cross-language consistency using PCG32 algorithm.

## Key Concepts
- Deterministic data generation
- Cross-language consistency
- Virtual arrays
- PCG32 algorithm
- Mock data for testing
- TypeSpec code generation
